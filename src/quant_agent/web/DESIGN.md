# Web UI 设计系统 (DESIGN.md)

> 量化研究工作台的单一设计真相来源（Single Source of Truth）。
> 覆盖范围：`src/quant_agent/web/static/*`。后端 API 契约保持不变。

## 设计目标

- **专业可信**：面向量化研究者的「暗色终端」美学，而非花哨的营销页。
- **数据优先**：用克制的色彩突出信号（买/卖/持有）与评分，弱化装饰。
- **零依赖**：延续标准库 `http.server` 托管，仅用纯 HTML/CSS/JS，不引入框架或 CDN。
- **可读性**：数字使用等宽对齐（tabular-nums），长报告使用清晰的排版层级。

## 视觉标识 — 「Midnight Terminal」

深色金融科技面板。背景为深蓝近黑的多层渐变 + 极淡网格，营造「终端」氛围。

| `--surface-2` | `rgba(255,255,255,.07)` | 输入/悬浮面 |
| `--border` | `rgba(255,255,255,.08)` | 默认描边 |

### 排版

- 字体栈：`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 数字：`font-variant-numeric: tabular-nums`
- 层级：页面标题 20px/700，区块标题 15px/600 带强调色，正文 14px/1.6

### 质感与动效

- **玻璃拟态**：卡片 `background: var(--surface)` + `backdrop-filter: blur(12px)` + 1px 描边 + 柔和阴影。
- **光晕**：强调元素（激活导航、买入徽章、主按钮）使用 `box-shadow` 扩散光晕。
- **悬浮**：卡片/行 `transition: transform .15s, border-color .15s`，悬浮轻微上移 + 描边变亮。
- **评分条**：4px 圆角轨道 + 渐变填充，按分值着色（低→`--bear`、中→`--warn`、高→`--bull`）。
- **加载**：旋转环 + 骨架屏占位，避免空白焦虑。
- **响应式**：≤860px 侧栏折叠为顶部横向导航，主区单列。

## 布局

```
┌─────────┬──────────────────────────────┐
│ sidebar │  topbar (页面标题 + 状态)      │
│  brand  ├──────────────────────────────┤
│  nav    │  view (panel: analyze/screen/ │
│  status │         reports)              │
└─────────┴──────────────────────────────┘
```

- 侧栏宽 248px，固定，玻璃质感；激活项左侧 3px 强调条 + 光晕。
- 主区最大宽度 1100px 居中，卡片间距 16px。

## 组件清单

| 组件 | 选择器 | 说明 |
|---|---|---|
| 侧栏品牌 | `.brand` | Logo 光晕 + 名称/副标题 |
| 导航项 | `.nav-item` | 图标 + 文字，激活态强调 |
| 输入卡片 | `.card` | 玻璃容器 |
| 文本/数字输入 | `input` | 深色 + 聚焦光晕 |
| 主按钮 | `.btn.primary` | 渐变 + 光晕 |
| 信号徽章 | `.badge.BUY/.SELL/.HOLD` | 圆角胶囊 + 光晕 |
| 评分条 | `.score-bar` | 轨道 + 渐变填充 |
| 选股网格 | `table.grid` | 行悬浮高亮 + 评分条 |
| 报告卡片 | `.report-card` | Markdown 渲染容器 |
| 数据警示 | `.watermark` | 红边警示横幅 |
| 提示气泡 | `.toast` | 底部玻璃 pill |

## 可访问性

- 所有交互元素有 `:focus-visible` 描边。
- 颜色不单独承载含义：信号同时用文字 + 徽章。
- 对比度满足 WCAG AA（正文 ≥ 4.5:1）。
